# Implementation Plans

Generated by the improve skill on 2026-11-14 from a student UI/UX audit of the
quiz, video activity, flashcards and student home ("My Assignments"), written
against `dev-paul` at commit `db70831b`.

Each plan is self-contained: an executor needs only the plan file and the
repo. Read the plan fully before starting, honor its STOP conditions, and
update your row when done.

This folder is separate from `docs/plans/` (the repo's own feature plans) and
from `AGENT_BACKLOG.md`. These are hand-off plans from one audit; delete a
plan file in the PR that finishes it, or move the folder's leftovers into
`AGENT_BACKLOG.md` if they go stale.

## Dependency notes

- The four plans touch disjoint source files and can run in parallel, one branch and one PR each, all targeting `dev-paul`.
- The one shared area is `locales/*.json`: plan 001 adds a top-level `quizSubmit` block and plan 003 adds keys inside `flashcards`. They do not overlap, but if both PRs are open at once the second to merge may need a trivial rebase.
- Suggested order if run one at a time: 001, 002, 004, 003 (by how many students each affects).

## For the maintainer

- **No feature flags are planned.** Each plan is scoped as bug fixes, recovery buttons and wording. The one real behaviour change is the confirmation before a self-paced quiz's final submit (plan 001), treated as matching the existing confirmation on part submits. Ask for a flag if you disagree; the plan says to call this out in the PR.
- **One device check is yours** (plan 004): after it ships to the dev site, sign in as a student on a Chromebook, press Sign out, and confirm you are not signed straight back in.
- **Two decisions are parked** (plan 003 notes): whether a student who cannot record may submit a Speak Check, and whether a skipped Speak Check card should be final.

## Findings considered and rejected

- A retired student-home layout still shipping: not true. `MyAssignmentsPage` renders only `StudentLandingV2`, with no flag choosing a layout.
- Drag-only matching and ordering: both already support tap-to-place, a keyboard sensor and up/down buttons.
- Student-home read cost on each return (about 22 listeners plus one read per assignment): plausible but unmeasured. Measure before planning.
- Dark "Quiz Submitted!" wait screen after a light self-paced quiz: real inconsistency, cosmetic, left for a later pass.

Whiteboard and paper answers, the review game, the stimulus viewer, guided learning, mini-apps and the `/join` code page. Nothing was tested on a real device or against a live session.
