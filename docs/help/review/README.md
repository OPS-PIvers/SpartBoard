# Review help content

Help content for the Review widget (docs/plans/QUIZ_REVIEW_SPLIT.md, D30). Agents don't write help content to Firestore; an admin imports these.

## Help article

1. Paste `review-help-article.md` into a Google Doc and share it with the district.
2. Admin Settings > Help Center > New item: Embed, the Doc's link, category "Quizzes & activities", widget **Review** only.

Tag it with Review and nothing else. Teachers without the `quiz-review-split` preview never see an item tagged only with Review.

## Live tour

`Start a self-paced review game.*.gl.json` is a live tour of the Start review dialog and the game board.

1. Guided Learning > Import, choose **Building**.
2. Try it with **Run live (draft)** on https://spartboard-dev.web.app with a Review widget and at least one quiz. The last six steps need a self-paced game started from the dialog.
3. Publish it in the Studio and turn on its Help Center toggle.
4. Admin Settings > Help Center > New item: Guided Learning, this set, widget **Review** only.

The first step points at the first quiz's Start button but waits for Next, so any quiz works.
