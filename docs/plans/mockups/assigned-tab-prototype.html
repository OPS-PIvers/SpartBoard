Prototype only · pretend it is

Try this

  1. It is Period 2. Ecosystems Pretest offers Open for P2 without you choosing a class. Click a row to see every class.
  2. Switch the clock to Period 5. Cells Quiz ends by hand, so a "still open" flag appears for P2. Nothing was hidden.
  3. Close every class of a quiz. It stays in Active until its scores are published, then moves to Done.
  4. Open the ⋯ menu for Close for all classes and Move to Done.
  5. Open Done and reopen a quiz for one class. It opens straight away; there is no second Start.

What changed from today

  • Two tabs. Done is a section inside Assigned.
  • One plain line per quiz. Click the row for each class.
  • Open, Pause, Resume, Close, Reopen. Each one names the class.
