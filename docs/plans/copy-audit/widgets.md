# Copy audit: widgets (all except Quiz and Guided Learning)

## 1. Summary

The heaviest permanent copy in this area is in the **widget settings panel**. Every widget now renders its settings from a schema (`components/widgets/*/settings.schema.ts`), and the legacy panel uses the same schema through `components/settings/legacy/SchemaSettingsFallback.tsx`. Three mechanisms put a permanent sentence under a control: the schema `help:` prop (25 fields), the `partnerWidget` `missingHelp:` prop (14 fields, shown whenever the partner widget is not on the board, which is most of the time), and roughly 20 hand-written `<p>` helper lines inside `settingsFields.tsx` custom renders. All the settings copy is in `locales/en.json` under `widgetSettings.*`, so most fixes are string edits in that file (plus de/es/fr). The recurring patterns:

- help lines that restate the toggle label (Weather, Video Activity, Schedule, Recess Gear)
- "Tip:" and "Pro-tip:" callouts (Poll, Scoreboard, Embed, Materials)
- "managed by your administrator" stub panels that fill an otherwise empty tab (8 widgets)
- implementation or internal leakage ("CSS defines 1 in = 96 px", "via Feature Permissions", "(A7)", "wire format separator", "Gemini's video understanding")

The widget faces and editors have less copy. The worst of it is the Video Activity creator's source picker, the Mini App assign/share panel, and a few permanent instruction lines on math-tool canvases. `config/tools.ts` has no descriptions. Dock and library entries are label plus keywords only, so there is nothing to cut there.

## 2. Top offenders

1. **Time Tool settings, "When the timer ends" section** (`TimeTool/settings.schema.ts:76-136`). Five partner cards stack up. Each missing partner shows a full sentence ("Add a Stations widget to rotate students automatically when the timer ends.") directly above an "Add Stations" button. That makes five near-identical sentences at once, and each one repeats its card's toggle label and button.
2. **Poll settings** (`PollWidget/settingsFields.tsx:418-423, 474-476, 560-562, 659-661`). It carries a "Tip:" line, a privacy sentence, an AI help line, a sentence explaining that "The green dot marks the question showing on the board" (colour-only status patched with prose), and a two-sentence intro under "Live device voting". All of these are permanent.
3. **Embed settings** (`Embed/EmbedContentControl.tsx:116-117, 149-150`, `EmbedVerifyControl.tsx:212-221`). A "Pro-tip:" line sits under the URL field, a two-sentence help sits under the code box, and a permanent grey info box says "Some websites prevent embedding for security. Use the Verify button above to check compatibility." directly under the Verify button.
4. **Math Tools settings** (`MathTools/settings.schema.ts:14`, `MathToolInstance/settings.schema.ts:81`). "Spawned true-scale tools inherit this PPI. CSS defines 1 in = 96 px; change it only if your display renders differently. Grade-level filters remain in Admin Settings." This is jargon plus an implementation detail plus an unrelated pointer, all in one help line.
5. **Managed-content stub panels.** The only thing in the Settings tab is a sentence, several of them wordy or leaking internals. Examples: Talking Tool "configured by an admin via Feature Permissions", Activity Wall's heading plus a 2-sentence paragraph, and Projects "Each project's steps and rubric live in its own editor." (`ActivityWall`, `TalkingTool`, `Catalyst`, `CarRiderPro`, `BlendingBoard`, `First5`, `MiniApp`, `stickers`, `Projects`, `PdfWidget` settingsFields.tsx.)
6. **Video Activity creator source picker** (`VideoActivityWidget/components/Creator.tsx:444, 479, 518, 553, 602`). An intro question sits over three option cards, each with a description line. The AI step then adds an italic "Note: AI generation uses Gemini's video understanding to analyze the content and generate questions."
7. **Mini App assign panel** (`MiniApp/Widget.tsx:246, 361, 370, 419`). Four explanatory paragraphs narrate the flow ("Name this assignment, then share the generated link with students.") and the mechanics ("view counts appear in the Shared archive").
8. **Projects editor** (`Projects/components/ProjectEditorModal.tsx:322, 485, 495`). "Shown to the group. It does not lock the step (A7)." leaks a plan decision id to teachers. The paste box also carries a two-sentence merge explanation.
9. **Weather / Schedule / Video Activity toggles.** Every toggle carries a help line that restates the label. For example, "Hide clothing recommendations" is followed by "Hide the suggested clothing card from the widget."
10. **Starter Pack settings** (`StarterPack/settingsFields.tsx:106-108`). "Captures all open widgets — their types, positions, and sizes — as a reusable starter pack. The background is not included." This has an em-dash parenthetical listing the obvious.
