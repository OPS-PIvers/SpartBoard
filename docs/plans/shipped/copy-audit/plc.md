# PLC copy audit (components/plc)

## 1. Summary

The PLC area carries a lot of permanent explanatory copy. Almost every heading has a gray sentence under it (hub, Settings, Learning Targets, Norming, Meeting Mode steps, Resources, Trash, Version History), and every settings toggle carries a description line. Three near-identical import modals (quiz, video activity, assignment) each open with a prompt plus two long "Synced / Make a copy" paragraphs that explain the sync mechanics ("Sync available pill", "frozen snapshot"). The worst surfaces are the Settings tab (5 section toggles with descriptions, one of them 3 sentences, plus section intros for Notifications, Meeting schedule, Norming levels), the Teammate Print modal (5 conditional info banners with em dashes and multi-clause explanations), the New PLC Assignment flow (a hint under every field, some swapped by state), and Meeting Mode (a subtitle under every step heading, and a Save step whose subtitle repeats the checklist beneath it). Em dashes are common in PLC defaults (at least 14 strings), and implementation words leak through ("PLC-mode", "Sync available pill", "from presence", "re-publishes", "pooled").

## 2. Top offenders

1. **Settings tab, section toggles** (`tabs/PlcSettingsTab.tsx:44-81`, rendered at :212). Five toggle cards each have a description. The Print-for-teammates one runs 3 sentences and ends "Turn this off for the whole PLC." That restates what the toggle does. The intro "Choose which sections appear in this PLC's dashboard. Any PLC member can update these." restates the heading.
2. **Settings tab, Notifications block** (`tabs/PlcSettingsTab.tsx:254, 286`). "Control how this PLC stays in the loop." is filler under the heading "Notifications". The digest toggle adds "…Off by default; any member can change this." (semicolon, and it narrates the default).
3. **Import modals, sync vs copy** (`PlcQuizImportModal.tsx:129-154`, `PlcVideoActivityImportModal.tsx:131-158`, `PlcAssignmentImportModal.tsx:130-157`). The same pattern is copied three times. Each has a prompt question and then two 20-25 word paragraphs that explain sync mechanics and name a UI pill.
4. **Teammate Print modal** (`PlcTeammatePrintModal.tsx:273-645`). A picker prompt with an em dash, then up to five info or warning banners. Two of them ("copyDeferred", "copyPending") are 30-word near-duplicates that end in "— which is before they can scan this stack anyway." The success body is 3 sentences.
5. **New PLC assignment, sharing slot** (`PlcNewAssignmentSharingSlot.tsx:76-135`). There is a hint under the heading, a hint under the name field, and a hint under the auto-sheet toggle. Each one swaps text with state, so the user sees 3 helper lines at all times. One of them has an em dash.
6. **Meeting Mode step subtitles** (`meeting/PlcMeetingSteps.tsx:177, 319, 497`, `meeting/PlcMeetingMode.tsx:461, 655`). Every step heading (Pick / Review / Decide / Act / Save) already asks the question in plain words, and each gets a second explanatory sentence as well. The Save subtitle repeats the checklist printed directly below it.
7. **Version History intro** (`versions/PlcVersionHistoryPanel.tsx:256`). "Recent saved versions of this shared assessment. Restoring re-publishes that version to everyone — the current version is kept in history too." It restates the title, uses an em dash and narrates mechanics.
8. **Learning Targets manager hints** (`settings/LearningTargetsManager.tsx:613, 633, 671, 833`). A hint sits under the add form, the paste panel, the CSV panel and the mastery cutoffs. The CSV one is a semicolon-laden spec sentence.
9. **Home v1 subtitle and hub intro** (`home/PlcHome.tsx:88` "Your collaborative space", `PlcIndexHub.tsx:79` "Open a Professional Learning Community to collaborate with your team.", `PlcIndexHub.tsx:177`). These are marketing and label-restating subtitles on landing surfaces.
10. **Empty states that write tutorials** (`bodies/PlcVideoActivitiesBody.tsx:895`, `bodies/PlcSharedBoardsBody.tsx:123`, `tabs/PlcAssignmentsInProgressSubTab.tsx:350`, `tabs/PlcAssignmentsCompletedSubTab.tsx:62`). Each has 2 sentences, and some give step-by-step instructions ("click the kebab").
