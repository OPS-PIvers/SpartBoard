# Shell copy audit

## 1. Summary

The shell is mostly lean: the dock, board nav, boards modal, backgrounds modal and assignments hub carry almost no permanent prose. The worst surfaces are the ones that open to a full-width page or card: the **Settings modal** (every section header has a description paragraph, every Behavior toggle has a restating sub-line, plus a "Tip:" box that repeats the section description and the "All boards" scope chip), the **sidebar pages** (My Classes, My PLCs, Google Drive each open with an intro paragraph; Drive adds a three-step "How it works" list that describes JSON files), and the **share / sub-share modals** (every mode card has a one- or two-sentence body with em dashes, and every input has a hint line, several of them narrating Drive ACL mechanics or leaking the `/subs` route). The shared assign flow in `components/common/library` spreads the pattern the furthest: `ToggleRow` and `AttemptLimitRow` put a `hint` line under nearly every toggle in the assign/settings panels, and the "what students see" ladder is written out twice with different words (`PublishScoresModal` via `publishScoreLevels.ts` and `VideoActivityBehaviorSettingsPanel`). The recurring tells are restating the label, em dashes, narrated mechanics ("injected as CSS variables", "saved as JSON files", "read-only Google Drive access… Auto-revoked then"), and the same explanation repeated on sibling rows or sibling modals (Synced / View-only / Copy bodies exist in three files).

## 2. Top offenders

1. **Settings > Behavior** (`components/settingsModal/sections/BehaviorSection.tsx`): section description + "All boards" chip + a sub-line under both toggles + a blue "Tip:" box. The description, the chip and the Tip all say "applies to all your boards". Four sentences for two toggles.
2. **Settings > Profile** (`components/settingsModal/sections/ProfileSection.tsx`): section description plus a 2-3 sentence description under each of the three groups (Buildings, Grades, Subjects) plus italic empty-state lines under two of them. About 9 sentences on one permanent pane.
3. **Sidebar > Google Drive** (`components/layout/sidebar/SidebarGoogleDrive.tsx`): intro paragraph, "Connected & Synced" + "Files sync automatically" status pair, and a numbered "How it works" list ("Boards are saved as JSON files in your Drive"). Implementation narration on a page teachers only visit to connect/disconnect.
4. **Share board modal** (`components/share/ShareLinkCreatorModal.tsx`): prompt sentence, four mode cards with long bodies (substitute body is 3 sentences with an em dash), then in substitute mode an intro plus a hint under each of three fields, and a PLC-scope description. Same bodies duplicated in `ImportShareModePicker.tsx`.
5. **Share with a sub** (`components/share/ShareWithSubModal.tsx`, `ShareCollectionLinkCreatorModal.tsx`): summary line, "updating" hint, end-time hint, and a two-sentence "subsHint" under "Who is covering"; the collection version leaks `/subs` and "read-only Google Drive access… Auto-revoked then. Must be @orono.k12.mn.us."
6. **Assign modal toggles** (`components/common/library/AssignmentSettingsToggleGroup.tsx`, `QuizBehaviorSettingsPanel.tsx`, `VideoActivityBehaviorSettingsPanel.tsx`): about 14 toggle rows each with a hint line, most restating the label ("Show correct answer on board / Display correct answer on the projected screen").
7. **Sidebar > My Classes / My PLCs** (`SidebarClasses.tsx`, `SidebarPlcs.tsx`): each page opens with an explanatory paragraph under the title; PLC one defines the acronym every visit.
8. **Settings > Appearance** colors note (`AppearanceSection.tsx:246`): "These are injected as CSS variables and used throughout the interface." Pure implementation leak.
9. **Publish scores modal** (`PublishScoresModal.tsx` + `publishScoreLevels.ts`): intro sentence with a colon, three radio cards whose bodies restate the titles, then two protection toggles with long descriptions.
10. **Remote Control menu** (`components/layout/RemoteControlMenu.tsx:121`): "Allow mobile devices to control this board." Restates "Enable Remote" and is wrong (the setting is account-wide).
