# Copy audit: Quiz (QuizWidget + student quiz app)

Paths below are relative to the repo root. `QW/` = `components/widgets/QuizWidget/`, `Q/` = `components/quiz/`, `CL/` = `components/common/library/` (shared panels that only render inside Quiz/VA, included because they are the Quiz Settings tab and Assign dialog).

## 1. Summary

The Quiz area carries a lot of permanent helper copy, concentrated in the teacher authoring surfaces: the editor's Settings tab (every toggle has a hint line), the Stimuli tab (a filled brand-blue "info" box plus a second explainer paragraph in the right pane), the editor's type callout, and the paper-sheet modals (Print, Import scan, Read test paper), where almost every step opens with a 2-3 sentence paragraph. The recurring patterns are: hints that restate the toggle label ("Sound Effects" / "Chimes, ticks, and fanfares during the quiz"), mechanism narration ("The file is read on this computer and never uploaded", "The bank is frozen when you assign"), the same reassurance repeated on sibling surfaces ("No student names are shared" x2, "Students will pick their period after entering the join code" x4, "Results then show the question a student missed, not just its number" x3), and em-dash compound sentences. The worst surfaces are the Quiz Settings tab (CL/QuizBehaviorSettingsPanel + AssignmentSettingsToggleGroup, ~16 description lines), the Stimuli tab (two permanent paragraphs saying overlapping things), the paper-sheet modals, and the legacy widget settings field (`widgetSettings.quiz.managementHelp`). The student app is mostly conditional state copy (paused, locked, provisional score) and is in better shape. The one real exception is the recording consent notice, which is a privacy disclosure and should stay.

## 2. Top offenders

1. **Quiz editor > Settings tab** (`CL/QuizBehaviorSettingsPanel.tsx` + `CL/AssignmentSettingsToggleGroup.tsx`). 3 mode cards each with a description, plus about 13 toggles each with a grey hint line. Most restate the label ("Show correct answer on board" / "Display correct answer on the projected screen"). The same panel appears again inside the Assign dialog's "Session Settings" section with an extra intro line on top.
2. **Quiz editor > Stimuli tab, right pane** (`QW/components/QuizEditorModal.tsx:680`). "Stimuli save with the quiz. Students see them beside the questions you assign them to — doc-shaped stimuli open in a side panel, media renders above the question." A whole pane used for a paragraph. The left pane (`QW/components/StimulusManagerPanel.tsx:259`) opens with a solid brand-blue box that explains stimuli a second time.
3. **Quiz editor > Settings tab, right pane** (`QuizEditorModal.tsx:688`). "Settings saved with the quiz are the defaults for live sessions and new assignments — you can adjust them per assignment in the Assign dialog." A permanent paragraph filling the detail pane.
4. **Question editor type callout** (`QW/components/QuizEditor.tsx:1078-1080`, text at 106/111/116). Solid brand-blue box with an alert icon on every Matching, Ordering and Choose-All question: "Pair terms with their matching definitions. Add extra distractors to increase difficulty." It uses warning styling for static help and repeats the type name.
5. **Paper Print modal** (`QW/components/PaperPrintModal.tsx`). Permanent sub-lines under the toggles ("Prints each question with its choices listed underneath, each beside its own bubble. Fits 5 questions per page."), a helper under the uploader, and the Sheet Images section (`PaperSheetStimuliSection.tsx:366`) that opens with a 4-sentence paragraph.
6. **Paper Import (scan) modal** (`QW/components/PaperImportModal.tsx:532, 602, 626, 675`). Every field has a helper sentence, including "Pages can be in any order, upside down, or split across scans. The file is read on this computer and never uploaded."
7. **Read test paper modal** (`QW/components/PaperQuestionTextModal.tsx:297, 318, 326, 373, 381`). Each step opens with a 3-sentence intro and closes with the same footer line ("Questions are matched by the number printed before them.") in both variants.
8. **Monitor > Settings screen** (`QW/components/monitor/QuizSettingsScreen.tsx:77-121`). 5 toggles, each with a description line that restates the label.
9. **Legacy widget settings panel** (`QW/settingsFields.tsx:22`, `widgetSettings.quiz.managementHelp`). "Import, edit, preview, and run live sessions from the Quiz widget. These shortcuts change the view shown there." Every teacher who opens the widget settings sees this.
10. **Schoology instructions modal** (`QW/components/SchoologyAssignInstructions.tsx`). An intro sentence, a decorative 3-chip diagram, then 4 numbered steps that repeat the diagram, then a closing paragraph. The diagram and steps say the same thing twice.
