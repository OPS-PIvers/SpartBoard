# Question banks and reassessment

**Status:** outline only, not grilled
**Origin:** lead-teacher feedback 2026-09-09: lower priority than targets; useful for
departments that want banks organized by learning target with random pulls for
assessment and reassessment.
**Depends on:** `docs/plans/QUIZ_LEARNING_TARGETS_TAGGING.md`

## Outline

- A bank is a pool of tagged questions owned by a teacher or a PLC.
- Building an assessment can pull N questions per target at random; reassessment reuses
  the bank with a different draw for the same targets.
- Pooled PLC data still groups by target so random draws stay comparable.
- Open questions: bank ownership and sharing; banks inside the quiz library or beside it;
  how randomization interacts with read-aloud and stimuli; whether per-student
  reassessment is a separate assignment type.
