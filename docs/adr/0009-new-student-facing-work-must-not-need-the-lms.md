# New student-facing work must not need the LMS

Schoology and Google Classroom keep running beside SpartBoard, and the district may stop paying for Schoology later. So every new student-facing piece (the Class page, the Agenda, Writing assignments, copied Google files) has to work for a class that has no Schoology or Classroom course, and keep working when it is opened from one. We chose this over building only for the parallel world, which would need rework if Schoology goes, and over naming a replacement date, which would make a gradebook-to-SIS sync, family access and course materials urgent before anyone has asked for them.

## Consequences

- The Class page is reached by its own link, which a teacher pins in the LMS once. Nothing depends on an LTI launch or a Classroom course.
- Families open the public Class page without signing in. It shows the Agenda and pinned links only, never a student's name or work.
- Student-facing folders, pages and a new discussion tool are not built. Materials are reached through the Agenda, and Activity Wall is the discussion tool.
- This sets no date for dropping Schoology and does not change the 2026-06-05 decision to keep its embedded launch for quizzes and video activities.
