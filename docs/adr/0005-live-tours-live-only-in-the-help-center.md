# Live tours live only in the Help Center

A Live tour is saved straight into the Help Center, Hidden and Unfiled, wherever the recording started, and the Guided Learning library never lists one. The alternative was to keep the library as an admin's workshop and give "Move to Help Center" a real one-step move. Paul chose a single home on 2026-11-12. A recorded tour was never personal (it is a building item every admin shares), and the Help Center is the only place a Live tour is ever used, so a second home only meant filing everything twice.

## Consequences

- An admin looking for a tour in the GL widget won't find it. The widget's record button stays, and its toast points to the Help Center.
- Unpublished work lives in the Help Center as Hidden items, so Hidden has to mean "teachers can't see this" everywhere.
- Existing tours were moved once by script ([HELP_CENTER_HOME.md](../plans/HELP_CENTER_HOME.md) H3). Going back to a library home would need the reverse move.
